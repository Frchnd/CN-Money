# CN MONEY v2.5.0 — COLORFUL PROFESSIONAL / ELEVATED CARDS

Scope release ini visual-only. Logic finance, Shopping, DATA, taxonomy, sync, offline, Back, DATABASE visibility, dan estimasi harga tidak diubah.

## Perubahan
- Light/dark neutral background diberi tint warna yang lebih hidup namun tetap profesional.
- Warna semantic yang sudah ada (Pengeluaran merah, Pemasukan hijau, Transfer biru, hero, warning/error/success) dipertahankan.
- LIST Belanja: setiap item tappable sekarang tampak sebagai card terangkat dengan outline cyan.
- DATA: card item memakai outline violet dan elevation.
- Anggaran Belanja: card detail memakai outline amber dan elevation.
- RECEIPT: card index memakai outline teal dan elevation.
- Saku / Investasi / Aset: masing-masing punya outline kontras berbeda tanpa mengubah isi/struktur card.
- Filter bulan Dashboard/Receipt/History dan filter grouping History diberi depth/outline agar jelas bisa ditekan.
- Tombol + utama serta + Saku/Investasi/Aset mempertahankan warna lama, hanya dibuat lebih timbul.
- Card netral seperti komposisi aset, summary investasi, cashflow, dan input belanja diberi depth ringan.
